## 项目简介

幻星4.1是一款完全自研的生成式AI语言模型，基于现代Decoder-only Transformer架构（RoPE + RMSNorm + SwiGLU），具备自然语言理解、文本生成、自由聊天、基础数学计算和语文知识问答能力。训练环境支持GPU加速、混合精度、梯度累积等现代训练技术。

## 模型架构（v4.0）

- **架构**: Decoder-only Transformer（GPT风格）
- **位置编码**: RoPE旋转位置编码
- **归一化**: RMSNorm（预归一化Pre-LN）
- **激活函数**: SwiGLU
- **注意力**: 因果自注意力 + PyTorch SDPA高效实现
- **权重绑定**: 输入Embedding与输出LM Head共享权重
- **默认配置**: 4层、4头、256维、约3.86M参数

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 训练模型

```bash
# 默认配置训练（CPU，全部功能）
python train.py

# GPU加速训练（自动检测）
python train.py --device auto

# GPU + 混合精度训练（推荐有GPU时使用）
python train.py --device cuda --use_amp

# 梯度累积（等效大batch，适合显存有限时）
python train.py --gradient_accumulation 4

# 早停机制（验证损失无改善时自动停止）
python train.py --early_stopping --early_stopping_patience 5

# 自定义训练参数
python train.py --max_iters 1000 --batch_size 8 --lr 3e-4 --n_layer 6 --n_embd 512

# 只保存最佳模型（节省磁盘空间）
python train.py --save_only_best
```

### 3. 自由聊天

```bash
# 交互式多轮聊天
python chat.py

# 单轮聊天
python chat.py --prompt "你好，你是谁？"

# 自定义系统提示词（AI人设）
python chat.py --system_prompt "你是一个专业的数学老师"

# 聊天命令
#   quit/exit: 退出
#   reset: 重置对话
#   history: 查看历史
#   system xxx: 修改系统提示词
```

### 4. 数学计算

```bash
# 交互式数学计算
python huanxing_math.py

# 单轮计算
python huanxing_math.py --problem "25 + 37 = ?"
python huanxing_math.py --problem "解方程：2x + 3 = 11"
python huanxing_math.py --problem "长方形长10宽5，求面积"
```

支持类型：基础加减乘除、分数、小数、简单方程、几何计算、应用题。

### 5. 语文知识问答（v3.0新增）

```bash
# 交互式语文知识问答
python knowledge.py

# 单轮提问
python knowledge.py --question "静夜思的作者是谁"
python knowledge.py --question "画蛇添足是什么意思"
python knowledge.py --question "四大名著是哪些"
```

支持类型：古诗词、成语典故、文学常识、语法修辞、文言文、阅读写作。

### 6. 文本生成

```bash
python generate.py --prompt "你好，我是幻星4.1，" --max_tokens 200 --temperature 0.8
```

## 训练特性（v3.0）

- **RoPE + RMSNorm + SwiGLU**：现代Transformer架构
- **自动GPU检测**：auto模式自动选择最佳设备
- **混合精度AMP**：FP16/BF16加速训练（GPU）
- **梯度累积**：等效大batch，突破显存限制
- **早停机制**：防止过拟合，节省训练时间
- **余弦退火学习率**：带warmup的学习率调度
- **梯度裁剪**：防止梯度爆炸
- **权重衰减**：AdamW优化器，区分衰减/非衰减参数
- **损失历史记录**：自动保存训练曲线数据
- **Top-k / Top-p / 重复惩罚**：多种采样策略
